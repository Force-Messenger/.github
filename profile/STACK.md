# Технологический стэк

Мы стараемся использовать самые новые и проверенные технологии из возможных. Ниже — актуальный состав платформы.

## Клиентские приложения

Web, desktop и mobile собраны из одного монорепозитория: доменная логика, работа с сетью и состояние вынесены в общие пакеты, а каждая платформа отвечает только за отрисовку и нативные интеграции. Поэтому поведение приложений совпадает, а новые возможности появляются сразу везде.

- **Интерфейс**: React 19, React Router 7, Radix UI, SCSS-модули
- **Состояние**: TanStack Query 5, Zustand 5
- **Сеть**: Axios, STOMP поверх WebSocket для реального времени
- **Локальный кэш**: IndexedDB — переписка открывается мгновенно и переживает перезапуск (в настольном приложении кэш шифруется)
- **Звонки**: LiveKit
- **Десктоп**: Electron 41 с автообновлением, трей и нативные уведомления
- **Мобильное приложение**: Expo SDK 57 + React Native 0.86 (в разработке; в дальнейшем планируется переход на Swift и Kotlin)
- **Сборка**: Vite 8, pnpm workspaces, Turbo
- **Отчёты об ошибках**: Sentry
- **Языки**: TypeScript 5.9
- **Локализация**: русский и английский во всех приложениях

## Серверная часть

- **Платформа**: Java 25, Spring Boot 4
- **Веб и API**: Spring MVC, OpenAPI / Swagger для описания контрактов
- **Реальное время**: STOMP поверх WebSocket (мгновенная доставка, статусы присутствия, набор текста, отметки о прочтении)
- **Безопасность**: Spring Security, JWT (Nimbus JOSE), хранение сессии в защищённых cookie, защита от перебора и ограничение частоты запросов
- **Звонки**: интеграция с LiveKit
- **Уведомления**: Web Push (доставка уведомлений на устройства, даже когда приложение закрыто)
- **Медиа**: разбор метаданных вложений (размеры, ориентация, длительность) и выдача файлов из объектного хранилища
- **Почта**: транзакционные письма (подтверждение регистрации, восстановление доступа)
- **Панель администрирования**: отдельное SPA-приложение для модерации и эксплуатации

## Хранение данных

- **PostgreSQL** — учётные записи, друзья и приватность, сообщества и роли, участие в чатах, звонки, гарантированная доставка сообщений
- **MongoDB** — тела сообщений и метаданные медиа
- **Redis** — статусы присутствия и обмен событиями реального времени между узлами, счётчики ограничения частоты запросов
- **S3-совместимое хранилище** — аватары и медиафайлы чатов
- **Flyway** — управляемые, версионированные миграции схемы базы данных

## Сайт

- **Лендинг и блог**: React 19 + React Router с рендерингом на сервере, Vite; юридические документы и план развития публикуются из того же репозитория

## Эксплуатация и наблюдаемость

- **Контейнеризация**: Docker / Docker Compose для локального окружения
- **CI/CD**: GitHub Actions — проверки на каждый коммит, выкатка сервера, веб-версии и панели администрирования, сборка релизов настольного приложения
- **Качество кода**: статические проверки клиента (линт, типы, границы между пакетами, полнота переводов, поиск мёртвого кода) и серверные тесты на JUnit + Testcontainers
- **Метрики**: Micrometer + Prometheus, проверки доступности (liveness/readiness)
- **Сборка**: Gradle (серверная часть), Vite (веб-клиент, панель администрирования, сайт)
